# 店の土台｜記事の飛び先（ワンドライを実物のコードから写した版）

読む人: 店を一回で作る Claude（`pdp-tsukuru`）と、土台を直す本人。
読む時: 店の設計（`店の設計.md`）を埋める前。
読まなくていい条件: 土台の変数の名前と既定が分かっていて、`店の印.json` だけを書く回。

**正本はこのファイル（`pdp-tsukuru/references/土台.md`）。**

空の型（`kata/index.html`）は、ワンドライのプレミアム LP の HTML と CSS をそのまま写した物。文字は全部〔ワンドライの元の文〕の札、絵は全部 `img/<名前>.png` を指す。店を作る回に替えるのは、札の中の文字・絵・末尾のスクリプトの「変えるならここ」だけ。CSS・タグ・クラスは1字も変えない（検査 F1 が数える）。

## 言葉の定義

| 言葉 | 意味 |
|---|---|
| 札 | 空の型の中の〔…〕。中身はワンドライの元の文。同じ役目・同じ長さ（元の字数の 0.7〜1.3 倍）で、うちの商品の文に替える。PC 用とスマホ用で同じ文が2回ある所・流れる帯・ボタンとその下の行は、全部に同じ文を入れる。〔絵の説明〕は絵ごとに書く |
| 絵の名前 | `kata/絵の一覧.tsv` の1列目（6列目の「地」は、参考の絵の地が透明か不透明か）。作った絵は `_gen/<名前>.png` に書き、`絵を置く.py` が `img/<名前>.png` に置く。ページの img タグは触らない |
| 参考の絵 | `絵の一覧.tsv` の5列目。その絵を作る時に、商品の実物写真と一緒に渡す写真。横送りの1枚目はワンドライ、2〜8枚目はここちドライ、ほかの段はワンドライの同じ絵 |
| 変わる | 商品が変わると値が変わる変数。◯ の行は `店の設計.md` の 4 で値と出どころを書き、`店の印.json` に入れる。✕ の行は空の型のまま触らない |
| 既定 | ワンドライに入っている値。出どころが無い時の仮の値ではなく「形の見本」として読む |
| 出どころの種類 | その値をどこから取るか。商品の事実／仕入先の数字／記事の約束／本物の声／客の資料／本人の決め／決めた値／土台 の8つ。本人の決めは `product.md` に本人が書いた値。そこに無い値は Claude が決めて `決めた値.md` に書き、出どころを「決めた値」と書く（止まって聞かない）。仕入先の数字は仕入先のページにある数字（寸法・素材・評価）で、`product.md` の「出どころ」に「仕入先の数字」と書いた物 |
| 本物の声 | 材料（プロダクトリサーチのまとめ・VSL の MD・`product.md`・客の資料）に原文がある、客の疑いや言葉。Claude が客の立場で考えた疑いは本物の声ではない |
| 記事の約束 | 記事が読み手に言い切った得（例: 見た目はいつもの下着のまま）。店はこれと同じ事を言う |
| 主役 | 写真1枚の中で一番大きく写っている物。言葉は「絵の種類」の節の一覧から選ぶ |

## 店の型は1つ

型は「オファー（値段とセット）が2スクロール目までに見える店」だけ。記事から来た人でも広告から直接来た人でも、店の中身は同じにする（入口ごとの版は作らない）。
この店の役目は、記事で疑いを処理し終えた人に信頼を出し、引っかかりなく買わせる最後の一歩。段ごと・部品ごと・写真1枚ごとに参考へ寄せ、差を0にする。

## 絵の種類（`絵の一覧.tsv` の3列目と、`画像の置き場.md` の「主役」に使う言葉）

写真（商品／手と商品／人の体と商品／人の体／人の顔／人の顔と商品／物／場面 のどれが主役かを `画像の置き場.md` に書く）・イラスト（写真でない絵）・図・札・ロゴ・アイコン・専門家。
犬の飾り（足あと・犬の絵）は空の型から消してある。足さない。

## わざと変える物（参考と違って当たり前。これに無い差が0になったら終わり）

文字の中身・写真に写る物（うちの商品、日本人で客と同じ年代と性別の人）・値段・保証日数・セットの数え方・専門家・客の声・数字・選ぶ所の有無・上の「入れない物」。

## この土台にまだ無い物・仮の物

- 色と書体はワンドライ（ペット用品）で勝っている物。他の客で勝つかは、工程8の数字が出るまで分からない
- 変数の「見る数字」はまだ仮。工程8（本人の環境の `python3 ~/Claude\ Code/ec-harness/段の落ち.py`）の段ごとの数字と照らし、動かない変数は ✕ に落とす
- 空の型を作り直す時は `scripts/空の型を作る/型を作る.mjs` → `型を組む.py`（参考の写し `references/参考_ワンドライ/index.html` から組む）
