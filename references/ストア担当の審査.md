# ストア担当の審査の決まり（編集長が店を審査する時に照らす物）

読む人: 店を審査する編集長（書いた本人でない Opus）と、店を出す Claude。
読む時: 審査の箱 `scripts/審査を回す.py` が、下の「## ストア担当の関門」と「## 審査の決まり」の2節を審査役に渡す時。
読まなくていい条件: 記事を審査する時（記事は記事の決まりで見る）。

店では記事の決まり（記事の題の型・15の事の欄・記事の最終確認のひな形）は当てない。その役目は、店の見出しの指示文と `店の設計.md` が持つ。

## ストア担当の関門

0. 新しく作る店は `pdp-tsukuru` の手順で作る。`product.md` に無い値は本人に聞かずに Claude が決め、止まらない
1. 今ある店を直す時は、直す理由が 割り付けの店の列・反論台帳の穴・アナリストの落ちた段 のどれかにある。出どころの無い直しはしない
2. 評価と件数・配送日数・保証日数を、広告・記事・店で突き合わせてそろえる（箱 A4。値段は並べるだけで、違いでは落とさない）
3. 規約・特商法は名指しの文だけ。決済アプリを足す・今ある店の値段を変えるのは本人の承認の後（新しく作る店の値段は `product.md` の値。無ければ Claude が決めて `決めた値.md` に書いた値で、これでは落とさない）
4. 作るのはローカルか非公開テーマ
5. スマホ（390px）と PC（1440px）の両方で検査を通す（最終確認 D1）
6. `scripts/店の検査を回す.py` の機械の検査が全部0
7. 判定は編集長。本番に上げるのは本人の承認の後
8. 薬機法・景表法の指摘は、言われた時だけ書類に入れる

## 審査の決まり

上の「ストア担当の関門」と、pdp-tsukuru の手順書（`SKILL.md`）の「最後の確かめ」の全部の箱で照らす。毎回、全部の箱を全部の段で上から順に見て、ずれを全部書く。前の回に○だった所も見直す。

| 照らす物 | 照らし方 |
|---|---|
| Claude が決めた値 | 専門家の名前と生成した顔・静止画3コマの動画・Claude が書いた客の声・Claude が決めた数字（評価の件数・使った人の％）・割引なしの値段の見せ方は、そのまま出す値なので落とさない |
| 見た目 | `並べて見た_<回>.txt` のいちばん新しい物の1行目が `安く見える所 0件` で、指紋が今の店の指紋と同じ事を確かめる（違えば FAIL）。見比べは手順10b の係が済ませているので、審査役は `並べた絵/` の画像を最初から数え直さない。開くのは、ほかの行（商品の形・絵）を照らすのに要る画像だけ。`並べて見る指示文.md` の「数えない物」の表にある物と、`並べて見た_<回>.txt` の「次の候補」に書いてある物では落とさない |
| 写真 | 絵1枚ごとに、`絵の一覧.tsv` の5列目の参考の絵と並べて見る。構図・文字と吹き出しと札の数と置き場所・質感が参考と同じで、替わっているのが商品・人・文字だけか。参考の絵の商品・犬・ロゴが残っていれば FAIL |
| 絵 | `絵の一覧_<n>.jpg`（`画像の置き場.md` の # の番号つき）を先に全部見て、気になった絵だけ `img/` を開く。絵ごとの「見えるべき物」は `絵と説明の一覧.tsv` |
| 最初の画面の見出し | `references/見出しの指示文.md`（得が1秒で分かる型。最初の画面に疑いの文・問いの文を入れない） |
| 来た人と本物の声 | `移植表_店の設計.md`（店の設計の写し）の「1 来た人」と「2 本物の声」。上の FAQ 4問（最初の画面の中）と見出しの「前の失敗」の言葉が、2 の表の原文から来ているか。Claude が考えた疑いが下の FAQ（15. よくある質問）以外にあれば FAIL |
| 商品の形 | 文と絵が言う商品の形が、`移植表_店の設計.md` の「0 商品の形」と同じ（違えば FAIL）。絵が商品の形と違うと数えるのは、買う人が商品を取り違える違いだけ: 部品の数・色・コードやつなぐ口の有無と本数・付ける面や敷く向き・覆う範囲が倍以上違う（例: 帯の商品が全面を覆う）。端の位置の少しの違い・大きさが倍より小さい違い・重なり方は数えない（絵を作る AI は位置と大きさを頼んだとおりに描けず、2026-11-14 の試しで照らし合わせが11回、4〜10件の間を行き来した）。絵と文（alt・説明）が食い違うだけの時は、文を絵に合わせる指摘にする（合わせる先は alt・`画像の置き場.md`・設計の 5 だけ。「0 商品の形」の言葉は変えない） |
| 数字・名前・場面 | `index.html`・`移植表_店の設計.md`・`決めた値.md`・`画像の置き場.md` の間で食い違っていないかを全文で照らす。画像は `画像の置き場.md` と `index.html` の画像が1対1 |
| 機械の検査 | `検査の結果.md`（`scripts/店の検査を回す.py` が書く。店の指紋つき）を読み、指紋が今の店の指紋（`python3 scripts/店の指紋.py <店のフォルダ>`）と違えば FAIL |
