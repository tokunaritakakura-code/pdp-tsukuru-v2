# 並べて見る指示文（出来た店を参考と並べ、作った本人でない AI が安く見える所を挙げる）

読む人: 店を出す Claude（pdp-tsukuru の手順10b）と、並べて見る別の AI（Opus）。
読む時: 手順10a（機械の検査）の後に毎回。`index.html` か絵を1つでも変えたら、もう一度。
読まなくていい条件: なし。

作った本人は、自分の店が参考より安く見える所に気づきにくい（2026-11-13 の試しでは、本人が気づかなかった所が1回目に31件挙がった）。段ごとに参考と横に並べた画像を作り、別の AI に見比べさせる。0件になってから審査に出す。

## 道具が見る所

- 並べた画像は `node scripts/参考と並べる.mjs <店のフォルダ>` が `<店のフォルダ>/並べた絵/` に書く（左が参考・右がこの店。一覧は `並べた絵/一覧.md`、その時の店の指紋は `並べた絵/指紋.txt`。指紋は `index.html` と `img/` の絵から出す12字）
- 結果は店のフォルダの `並べて見た_<回>.txt`（`<回>` は1から。回すたびに1つ増やす）。1行目は `安く見える所 <数>件`、2行目は `指紋: <指紋.txt の12字>`
- `scripts/店の検査を回す.py` は、いちばん新しい `並べて見た_<回>.txt` の1行目が `安く見える所 0件` で、2行目の指紋・`並べた絵/指紋.txt`・今の店の指紋の3つが同じ時だけ通す

## 数える物

| # | 数える | 例 |
|---|---|---|
| ① | 色・書体・角・影・余白が左と違う | ボタンの色が違う、字が丸い書体になっている |
| ② | 段の骨組みが左と違う | 左にある部品が右に無い、左に無い箱や札が右にある |
| ③ | 文字が枠からあふれる・切れる・重なる | ボタンの字が切れる、吹き出しから字がはみ出す |
| ④ | 文字が長くて形が崩れる | 見出しが左より2行以上多い、段の高さが左の1.3倍を超える、最後の1字だけ次の行に落ちる |
| ⑤ | 絵が抜けている・枠が空・同じ絵が2か所以上にある | 灰色の四角、割れた絵の印、白い四角が残った絵 |
| ⑥ | 絵の作りが左より粗い | 絵の中の日本語が崩れている、肌や物が作り物に見える、切り抜きのふちが残っている |
| ⑦ | 絵の構図が左と違う | 左は真上から、右は斜めから。吹き出しや札の数・置き場所が違う |
| ⑧ | 参考の物が残っている | ワンドライの商品・犬・ロゴ・字 |

## 数えない物（この節が正本。渡す指示文はこの節を指す）

## 渡す指示文（このまま渡す。`{}` だけ埋める）

> あなたは店の見た目の検査役。作った人の説明は聞かず、画像だけで判断する。褒めない。一般論を書かない。
> `{店のフォルダ}/並べた絵/一覧.md` を Read で読み、そこにある画像を上から全部 Read で開く（1枚も飛ばさない。日本語で答える）。どの画像も、左が参考の店・右が今作っている店で、同じ段を並べてある。`00_横送り_N.png` は、左が参考の写真・右が作った写真。
> 先に `~/.claude/skills/pdp-tsukuru/references/並べて見る指示文.md` の「数える物」と「数えない物」の2つの表を Read で読み、その線で、段ごとに右が左より安く見える所を挙げる。「数えない物」の表にある物は挙げない。迷ったら挙げる。
> `{店のフォルダ}/移植表_店の設計.md` の「0 商品の形」も先に Read で読む（数えない物の表が、商品の大きさの所でこれを指す）。
> 出力の1行目は `安く見える所 <数>件`。2行目は `指紋: {指紋}`。3行目からは「段の名前（画像のファイル名）: 数える物の番号｜右の何が｜左ではどうなっているか」を1件1行。ファイルは直さない。

`{指紋}` は `並べた絵/指紋.txt` の中身。受け取った出力を、そのまま `並べて見た_<回>.txt` に書く（頭の行は付けない。1行目が数）。

2回目からは、件数に入れる物を次の2つに絞る。回ごとに係が別の所を数えて件数が下がらないのを止めるため（2026-11-14 の試しで、21〜30回目が 3→11→8→10→10→8→8→8→7→6件と下がらなかった）。

| 2回目からの件数に入れる | 入れない |
|---|---|
| 前の回に挙がって、直っていない物 | 前の回から変えていない絵・段で、新しく見つけた物（「次の候補」として下に書くだけ） |
| 前の回から変えた絵・段で、新しく見つけた物 | — |

ただし「次の候補」のうち、数える物の ⑤（絵の抜け・空の枠）と ⑧（参考の物が残っている）は件数に入れる。

2回目からの指示文は、「渡す指示文」の終わりに次を足す: 「これは {回} 回目。前の回に挙がった所は `{店のフォルダ}/並べて見た_{前の回}.txt`。前の回から変えた絵と段は: {変えた絵と段の名前}。1行目の件数に入れるのは、ア 前の回に挙がって直っていない物、イ 変えた絵と段で新しく見つけた物、ウ 変えていない所でも、絵が抜けている・参考の店の物が残っている物、だけ。変えていない所で新しく見つけたほかの物は、最後に『次の候補:』と書いた下に1件1行で書き、件数に入れない」。2回目からも全部の画像を渡す（直した所の隣が崩れる事がある）。`{変えた絵と段の名前}` は、前の回の後に `_gen/` に作り直した絵の名前と、`index.html` の文を変えた段の名前（`ls -t _gen | head` と、自分の直しの控えから出す）。「次の候補」は、0件になった後・審査（手順11a）の前に、直せる物を直し、残りを `スキルの穴.md` に写す。

## 挙がった所の直し方

| 挙がった物 | 直す所 |
|---|---|
| ①② 色・書体・骨組み | CSS・タグ・クラスを空の型に戻す（`店の仕上がり検査.py` の F1 が違う所を言う）。CSS を足して直さない |
| ③④ 文字のあふれ・長さ | 札の文を短くする（元の文の字数の 1.3 倍まで） |
| ⑤ 絵の抜け | `_gen/<名前>.png` を作り、`絵を置く.py` を回す |
| ⑥⑦⑧ 絵の作り・構図・残り | `写真の指示文.md` の型で、参考の絵を付けて作り直す |
| 空の型の作りそのもので、札と絵では直せない物 | 直さず、作業場の `スキルの穴.md` に1行書いて報告する。同じ種類の物だけが2回続けて残ったら、そこで止まる |

直したら `参考と並べる.mjs` を回し直し、回を1つ増やして、もう一度 Opus の Agent に渡す。
